The scanner tries to read test-name/value rows across a report, not just three markers. It compares values only when a range is printed on the same line; other results are marked for clinician review.

It cannot diagnose every disease. OCR and report layouts vary, so check extracted values against the original. The vegetarian/non-vegetarian menu is general and is not a treatment plan for an abnormal result.
